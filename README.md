# vivobook-tune

Управление питанием и разгоном для ASUS Vivobook Pro 15 M6500QC
(Ryzen 5 5600H + RTX 3050 Laptop 4 ГБ) на Linux Mint 21 / ядро 6.8 (`amd_pstate`).

Меню открывается по **Super+Insert**: режимы питания, частоты и ядра CPU, EPP, лимит мощности,
вентилятор, режим NVIDIA, разгон GPU, живые графики частот.

## Установка

```sh
sudo ./install.sh        # меню, сервисы, sudoers, udev, хоткей
sudo ./lab-setup.sh      # для экспериментов: CUDA, gpu-burn, memtest_vulkan, Dynamic Boost
```

Разовые скрипты настройки системы (запускались один раз, лежат для истории):
`kernel-upgrade.sh` (ядро 6.8 HWE + `amd_pstate=active`), `pstate-setup.sh` (TLP под amd_pstate),
`gpu-setup.sh` (сон NVIDIA через RTD3), `cleanup.sh` (старые ядра и драйверы).

## Режимы

| Режим | Что делает |
|---|---|
| performance / eco | профили TLP от сети и батареи |
| user | свой профиль: частоты, ядра, EPP, лимит CPU, вентилятор, разгон GPU в безопасных пределах |
| lab | эксперименты: шире пределы (CPU до 60 W, GPU core до +1000, mem до +6000), работает сторож `hw-lab` |

Профили хранятся в `/etc/cpu-menu/user/` и `/etc/cpu-menu/lab/`, переживают перезагрузку и смену питания.

## Компоненты

| Файл | Назначение |
|---|---|
| `cpu-menu` | TUI-меню на curses (`cpu-menu-gtk` — старая GTK-версия) |
| `cpu-tune` | root-помощник через sudoers, проверяет все аргументы |
| `power-mode` | переключение профилей TLP и режимов user/lab |
| `cpu-fan-guard` | сервис: мощность CPU по RAPL, вентилятор, возврат разгона GPU после сна |
| `hw-lab` | сервис lab-режима: телеметрия в CSV, сброс разгона при перегреве или Xid |
| `nv-oc` | оффсеты частот NVIDIA через NVML |
| `kbd-idle` | гасит подсветку клавиатуры через 5 минут простоя |

## Эксперименты с GPU (lab)

| Скрипт | Назначение |
|---|---|
| `gpu-limit-find` | потолок разгона ядра: шаги оффсета + gpu-burn с проверкой вычислений |
| `gpu-mem-find` | потолок разгона памяти: memtest_vulkan, ошибки + пропускная способность |
| `gpu-backup` | полный бэкап EEPROM карты через nvflash (только из TTY) |
| `gpu-flash` | прошивка vBIOS с проверками и чтением назад (только из TTY) |
| `gpu-dump` | дамп через sysfs: только legacy-часть 64 КБ, для восстановления **не годится** |
| `rom-inspect` | сравнение образов vBIOS: Board ID, subsystem, версия |

Прошивки (`firmware/`), сторонние инструменты (`tools/`) и RyzenAdj в репозиторий не входят.

### Результаты на этом ноутбуке

| | 35 W сток | 50 W Dynamic Boost | + разгон (+150 / +2000) |
|---|---|---|---|
| gpu-burn | 3170 GFLOPS | 3770 GFLOPS | 3910 GFLOPS (15 мин, 85°C, 0 ошибок) |
| Память | 149 GB/s | 149 GB/s | 173 GB/s |

- Dynamic Boost работает только от сети в профиле `performance` и требует D-Bus-политику для `nvidia-powerd`.
- Ядро: +250 стабильно под полной нагрузкой, но даёт ошибки на высоких частотах при лёгкой нагрузке, поэтому выбрано +150.
- Память: без ошибок до +2250, на +2500 карта падает с Xid 62 (зависание прошивки, лечится перезагрузкой).
- Плата Board ID 02A6 (35/50 W). Доноры с 60/75 W — это плата 02A3, обычный nvflash их не прошивает.
- Curve Optimizer (андервольт CPU) заблокирован в BIOS 306: SMU отклоняет команду.

## Предупреждение

Разгон, лимиты мощности выше заводских и прошивка чужого vBIOS делаются на свой страх и риск.
Перед прошивкой обязателен полный бэкап (`gpu-backup`), а для отката «мёртвой» карты нужен
SPI-программатор (CH341A + прищепка SOIC8).
